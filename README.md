# GalaxFlow

A modern, high-converting digital agency landing page built with Next.js, Tailwind CSS, GSAP, and Lucide/HugeIcons.

## 🚀 Features

- **Fluid GSAP Animations**: Smooth reveal animations, magnetic interactions, and responsive motion.
- **Modern Agency Design System**: Curated dark theme, glassmorphic accents, and clean typography.
- **Interactive Components**:
  - Hero section with live badges and glowing CTAs
  - Dynamic Service offerings & capabilities
  - Interactive Workflow & Process section
  - Beam Wordmark Footer with quick navigation
- **Fully Responsive**: Optimized for desktops, tablets, and mobile devices.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: GSAP
- **Icons**: HugeIcons & Lucide React
- **Language**: TypeScript

## 📦 Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
